grep：

查找文本

格式：grep 文本 目标文件

grep -i 忽略大小写

grep -n 显示行号

grep -r 递归搜索目录（子目录）

ps

查看进程

ps -aux

a：所有用户的进程

u：展示用户、CPU、内存等详细信息

x：包含没有终端的后台守护进程

kill

终止进程

ip/ifconfig

查看和配置网络接口信息

ping

查看与主机的连通性

chmod

修改文件权限

chmod +/-r（阅读权限）

chmod +/-w (修改权限)

chmod +/-x（执行权限）

choud

修改文件属主，属组

chown [参数] [用户][:组]文件/目录

chown -r 递归修改文件

cat

显示文件内容

mount/umount

挂载/卸载挂载

mount语法：

mount 设备 挂载点

umount 设备/挂载点

挂载可以把独立的储存快绑定一个目录，让我们能够查询里面的内容，一个目录只能绑定一个设备，查询完后要卸载

tar

打包，解压，压缩文件

tar语法：

tar [参数] 包名 源文件/目录

tar -c 打包

tar -x 解压

tar -t 查看包中内容不解压

tar -z gzip压缩 .tar.gz（后缀）

tar -j bzip2压缩 .tar.bz2(后缀)（压缩率高，慢）

tar -J xz压缩 .tar.xz（后缀）（压缩率最高，最慢）

tar -c 解压到指定文件

tar -f 创建包名，f紧跟包名

zip / unzip

压缩，打包，解压

语法：

zip 压缩包名.zip 要压缩的文件/目录

zip -r 递归压缩，可以将子文件也压缩

unzip 解压

语法：

unzip 压缩包名.zip

unzip -l：只查看压缩包里的文件，不解压

useradd/userdel

需要 sudo 管理员权限 添加用户、删除用户

useradd 添加用户

语法：

useradd -m：自动创建家目录

useradd -G：加入附加用户组

useradd -s /bin/bash：指定登录 shell

userdel 删除用户

语法：

sudo userdel 用户名

只删除用户账号，家目录、文件还留在 /home 里，不会删掉

userdel -r：删除用户 同时删掉家目录和文件

passwd

修改用户密码

passwd # 不加用户名：修改自己的密码

sudo passwd 用户名 # 修改指定用户的密码（他人的）

passwd -l：锁定用户账号（锁住，不能登录）

passwd -u：解锁

passwd -d：清空密码

passwd -S：查看用户密码状态

cron

让系统在指定时间自动执行命令

cron 是后台服务；我们写定时规则用crontab命令

top/htop

查看系统进程

top系统自带/htop需要安装（top升级版）

psql/mysql

MySQL：开源关系型数据库

PostgreSQL：功能更强、标准更严谨的数据库

语法：

mysql/psql -u 用户名 -p 密码

mysql/psql -h ip地址 -P 端口 -u 用户名 -p 密码

ssh

远程登陆其他计算机

语法：

ssh 用户名@ip地址

ssh-keygen

生成 SSH 密钥，实现 ssh 免密登录

密钥对应两个文件 私钥（id_rsa）公钥（id_rsa.pub）

本地用私钥加密，服务器拿公钥验证，验证通过就不用输密码

scp

将本机文件上传到远程计算机上

语法：

scp 源文件 目标地址

scp -r 所有文件包括子文件

fing

查找文件/目录

语法：

find 搜索路径 匹配条件 文件名

演示：find . -name “test.txt”

. 代表当前目录

/ 代表从根目录全盘搜索

sed

对打印出来的文本进行编译，不会修改源文件

sed ‘操作’ 文件名

sed -i 修改源文件

s/// 替换

s/旧内容/新内容/

s/旧内容/新内容/g（全局，一行里所有匹配到的都替换；不加 g，只替换每行第一个）

d 删除

p 打印（sed -n （只输出匹配的行，不输出全部文本））

a 匹配行后面追加

i 匹配行前面插入

分隔符不一定只能用 /，如果内容里有斜杠，可以换成 #

hostname

查看主机名称

sudo hostname 新用户名 可以临时修改主机的用户名

netstat / ss

查看上网链接，端口占用情况

ps/top/htop

ps 执行命令这一刻，拍一张所有进程的照片，输出之后就固定不动了，不会自动刷新，适合查找

top 持续动态刷新，实时看系统负载、进程资源占用

htop top增强美化版 需要自己安装

history

查看在终端里敲过的所有历史命令

free

查看内存，交换分区的使用情况

free -h 转化成（G/M）单位

lsblk/fdisk

都可以查看磁盘、分区信息

lsblk 只能查看

fdisk 可以查看也可以新建，修改，删除分区

stat

查看文件/目录的详细信息

nmcli

管理网络链接

dd

底层数据拷贝工具，直接读写磁盘 / 文件，按块复制

语法：

dd if=输入源 of=输出目标 bs=块大小 count=拷贝块数

不写 count，dd 会一直读源文件，读到末尾才停止

awk

按列处理文本

语法：

awk ‘条件{动作}’ 文件

例如：

#打印第1列和第3列

awk ‘{print $1,$3}’ test.txt

  • $0：整行全部内容
  • $1：第 1 列
  • $2：第 2 列
  • $3：第 3 列
  • NF：当前行一共有多少列
  • NR：行号（第几行）

date

输出系统时间

修改时间必须加 sudo

date 查看当前时间

date -s 修改、设置时间

echo

在终端打印输出文字，相当于print

语法：

echo 文本

带空格、特殊文字，加引号

echo “hello world”

sudo

以超级管理员权限，执行后面的一条命令，是临时的

su 切换身份，直接变成超级管理员，之后所有命令都是最高权限，直到输入exit退出

ln

创建链接（快捷方式）

有两种链接：软链接、硬链接

软链接及快捷方式，用于快速打开文件

ln -s 源文件/源目录 链接名 （软链接）如果源文件和链接在同一个目录里不需要写绝对路径，不在则需要写

硬链接为文件多建立一个名字

uname

用来查看内核、硬件架构信息

shutdown/reboot

两个都需要管理员权限，要加sudo

语法：

shutdown 时间 [提示文字]

shutdown -h：关机

shutdown -r：重启

shutdown -c：取消已经安排好的关机 / 重启

reboot 直接重启 和shutdown -r now一样

sudo reboot -f（强制关机，可能会损坏打开的文件）

who/w

查看有哪些人登录

who 简洁版 列出：登录用户名、终端、登录时间、登录来源 IP

w是 who 的加强版，展示的信息更多

curl

发送网络请求、访问网址

语法：

curl 网址

curl-o（小写 o）：把下载内容保存成指定文件名

curl-O（大写 O）：用网址里原本的文件名保存

curl-I：只拿响应头，不下载页面内容（检测网站通不通、看状态码）

curl-X：指定请求方式（POST / GET）

curl-d：POST 提交数据

当网站拒接curl访问时，可以加-A 伪装成浏览器

uptime

查看系统开机多久、负载如何
